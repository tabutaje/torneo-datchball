# Torneo de colpbol en clase · 4º, 5º y 6º de Primaria

Web para llevar el torneo de colpbol de Educación Física desde el móvil, la tablet o la pizarra digital.

- **Reglas** del colpbol escolar y del torneo cooperativo.
- **Equipos**: nombres y reparto rápido del alumnado.
- **Calendario y actas** para 4 o 5 equipos, con resultados, juego limpio, punto extra y tarjetas verdes.
- **Clasificación** automática (resultado + juego limpio, con los desempates del torneo).
- **Cronómetro** de 2 × 6 minutos con descanso y aviso de cambio cada 3 minutos.
- **Roles, semáforo de conflictos y evaluación**.

Los datos se guardan solo en el navegador de quien usa la web. Con «Guardar copia» se descarga un archivo `.json` y con «Cargar copia» se recupera en otro dispositivo.

## Publicarla con GitHub Pages

1. Crea un repositorio en GitHub (por ejemplo `torneo-colpbol`) y sube `index.html`, `README.md` y `.nojekyll`.
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`, **Save**.
3. En uno o dos minutos la web queda en `https://TU-USUARIO.github.io/torneo-colpbol/`.

No hace falta instalar nada: es un único archivo HTML sin dependencias.
